2026年11月

12/7（土）

今日は 数物セミナーの大岡山談話会 に参加していた。昼過ぎの講演の座長を頼まれていたのだが、せっかくなので午前から参加することにした。前日がバイトで遅いこともあり１コマ目は休ませてもらったが...。

ひとつめは熱力学の講演を聞いた。教養の熱力学で何が何に従属しているのか混乱して挫折した私でも、熱力学が現実を予言するさまはすごいなぁと思っていた。教養の講義では平衡状態で系がどうなっているのかということしか扱えなかったが、今回の講演では、両端が別の温度の熱浴に接触している（そして液体と気体が共存している）筒の中で、熱が流れる様子も含めて定常化しているような系の状態を扱えるらしかった。計算すると過冷却/過加熱現象が予言されるというのはすごいと思った。筒を縦にして下部を加熱し上部を冷却すると、計算上では液体が気体の上に浮く現象が起きるらしい。すごい話だ。

発表の途中で、液体浮遊現象のシミュレーション動画（このプレプリント の Ancillary files のところにおいてあるファイル）を見せてくれる場面があった。arXiv 投稿に動画が付随しているのは数学では見たことがなかったので面白かった。シミュレーションには説得力があったものの、過冷却とは違い、液体浮遊は実験では再現されていないらしく、その事実が個人的には一番興味深かった。理論側の問題なのか実験器具側の問題なのかと質問してみたところ、外部から液体と気体の界面部分の温度を1K単位で操らなければならず、筒からの輻射のようなブレだけでぶっ壊れてしまうので実験で理想的な条件を達成するのが非常にハードだという話だった。物理ならではの難しさで大変そうだ。

ふたつめはリッチフローと熱方程式についての講演を聞いた。リッチフローで時間を正に進めたときの幾何学の変化をはかるにあたり「時間を遡るように熱を流す」という方法があって、熱核というかエントロピーの変化に関する強力な制約を利用することで、ヤバい幾何学が周囲に伝播するような現象に制約がかかったり、フローの先の幾何学を（例えば「位相多様体になる」みたいな結論として）制御できたりするという話だったと思っている。

めちゃくちゃ面白かった。もちろん細かいところは私には到底分からない数学なのに、大量の図と巧妙な省略によってなんか分かった気になれる神講演だった。本当にすごかった。「エントロピーがある時点でゼロになるならガウシアンに一致する」という剛性が非常に強く働いていたと思うが、並び立ってどうしようもなく強いのはやはり何らかのコンパクト性、つまり空間の極限の存在という形の定理だなぁと思っていた。当然「エントロピーがゼロになるなら」という定理はエントロピーがゼロでない場合には使えないはずで、エントロピーがゼロに漸近したところでどうしようもないよなぁと思っていたら、コンパクト性より極限となる空間を実際に取ってこれますと言われ横転した。のが２回あった。代数幾何的にもモジュライのコンパクト性は最も大変な部分のひとつだとは思うのでこういう話にはもっとアンテナを高く持っていきたい。

みっつめは私は座長ということになっていた quiver variety の構成を聞いた。まず GIT 商の一般論を展開した後、シンプレクティック幾何学の基礎を揃え、（技術的には GIT 商により）所謂 symplectic reduction の技術を用意する。箙の表現から構成される多様体に逆向きの辺を付け加える操作は余接束を取る操作と解釈でき、moment map を用意して symplectic reduction によって作られる多様体が　Nakajima quiver variety である。

私は GIT 商の理論は向井モジュライⅡで勉強し、symplectic reduction は Silva の lsg で勉強したので、繋がりが分かっていなかった。前者は無限回使うが後者は教科書に突然出てきただけでよくわかっていなかった。それを今回実際の例で見ることができて本当に神だった。今回の場合は商にシンプレクティック構造が引き継がれるらしい。面白い匂いがプンプンする。参考文献の一番上にあった Quiver Representations and Quiver Varieties を見てみたが滅茶苦茶凄いことを言っていた。ある種の Hilbert スキームや Springer resolution、インスタントンのモジュライが箙多様体として構成できるとか、McKay とか Hall algebra とかと関係していそうだったり、面白そうだ！！

よっつめは、微分幾何で見る電磁場という講演を聞いた。電磁気はいちおう教養学部で軽く勉強したものの、過去問に沿って最低限の勉強だけをして単位を取った記憶がある。たしかに Maxwell 方程式の形はよくわからないなぁと思っていたが、Hodge-＊ や擬リーマン計量による musical iso で書けるというのは全く知らなかったので面白かった。最後のひとつの式にまとめるパートは微分幾何らしく添え字が爆発して大変だなぁと思ったが、最終的に出てくるものは非常に整理された形になっていて、おおこれなら扱えそうかもと思えて凄かった。解析力学ももう少しどうにかなりませんかね？

最後は関数不等式の講演を聞いた。Young の不等式を定数倍改善できるかという問いに対し「実はできるし、最良定数を完全に決定することも可能である」というストーリーを提示してから話が始まった。そもそも私は世の中のすべての不等式は最良だと思っていたのでこの時点でびっくりしていた。Young の不等式は BL 不等式という非常に一般的な形の不等式の一例になっている。BL 不等式は単純な形の BL 不等式に変形できる場合がある。そして単純な形の BL 不等式は（熱方程式を使う非自明な解析によって）最良定数がピッタリ１であると求めることができる。よって元の Young の不等式の最良定数を求めることができて、これは１より小さいと計算される。

今日聞いた講演の3/5で熱という単語が出ていてがちですごい。最近本当にいろんな人から熱の話を聞く。時間発展とは言いつつ、局所的な情報が大域に及ぼす様子を見ることができるというのが強いみたいな感じなのだろうか。なにも分からない。

その後の懇親会では本当にいろんな人と話せてめちゃ楽しかった。東工大で数論/表現論/複素微分幾何をされている方々や、東大の後期教養で物理をされている方、そのほかにも数物セミナーなどでの友人たち、それから理物志望の後輩などなど、ピザを食べながら話して自分にない思想と情報をいろいろ仕入れることができた。東工大はいまいちどんな様子なのか仕入れる機会がなかったので色々話を聞けたのは貴重だった。千葉大はミラーの人がたくさんいるらしい、が、なかなか知り合う機会がない。どうにかしてお話したいが。あとその後輩にちょっかいをかけて共通の話題の話をいろいろ探っていたら、私と似た興味のB3が理物に居ると教えてもらった。激アツすぎて小踊りしたものの、落ち着くと心当たりがあり、もしやと思って聞いてみたら案の定教養学部自体の同クラだった。当時からめちゃくちゃ物理をやっているのは聞いていて、追いつける人がいないから空き教室で黒板を使ってひとりゼミをしているという噂だった（そしてなんと Physics Lab の数理物理班長になった今もそれは続けているらしい）。思えば、以前駒場の書籍部で偶々会ったときに、彼は複素幾何とかシンプレクティック幾何の話をしていたのだが、当時は私がそこまでミラーミラーしておらず代数幾何メインだったからぴんと来ていなかった。こんな都合のいい人間関係はない。教養学部にも意味ってあったんだと思った。明日の古田先生の追悼研究集会に彼が来るらしいので、声を掛けに行こうと思う。

11/8（日）

古田先生の追悼研究集会 に行った。私は古田先生に直接教えていただいたことはないが、先輩方からは良い先生だったというのを口々に聞いていた。講演の節々に差し込まれるエピソードトークでお人柄をほんの少し窺い知ることができた。行ってよかったと思う。

追悼集会といいつつ、古田先生の教え子や共同研究者の方々が、当時の数学的背景と照らし合わせながら古田先生の業績をなぞりつつ、自分の最近の研究紹介までするという、しっかり数学的に重量のある講演会だった。ゲージ理論も４次元トポロジーも指数定理も知らないのでなかなか難しかったが、会いたい人もいたので朝から参加した。

午前中は「Yang-Mills ゲージ理論とその４次元トポロジーへの応用」「Seiberg-Witten 理論とその４次元トポロジーへの応用」の２講演で、ゲージ理論をトポロジーに応用すると非自明な幾何学が分かる、といった話だった。Yang-Mills 方程式なるもの解（インスタントン？）を調べることはなんか物理的にも意味を持っているらしく、大事らしい。４次元トポロジーでは、インスタントンのモジュライが１次元になったりする状況で、"非線形波動発生器"で作ったインスタントンが端っこに流れて逃げていかなきゃいけないみたいなことが分かって、その際にエネルギーが保たれるとかみたいなことを勘定すると、Ｋ群のある元が消えていないみたいな非自明な結論を得ることができるみたいな話だった、ような気がする（そのときはなんか図を見て、なにか分かった気になったがなにもわかっていない。そもそもその後の講演も全部ボリューミー過ぎて頭がパンクしている）。

別の方向では４次元多様体について 11/8-予想という第２Betti 数と交叉形式の符号数の間の不等式予想があるが、これに肉薄する 10/8 不等式というのを古田先生が示されたらしい。これは結果以上にその証明における有限次元近似という技術が多方面に影響を与えた、らしい。こちらも聞いているときは面白かったし当然もう少し覚えていることを書こうと思えば書けるが、ビデオアーカイブに残るからとメモを取らなかったのは失敗だったかもしれない。とにかく面白かったし刺激になった。代数幾何では基本的に「流す」という動詞を使うことが無いと思う。manifold 上でフローを流すというのは、多様体で無限小でない移動をするときの常套手段として私でもよく使うし、これはODEの基礎理論から保証される技術だったと思うが、熱はたぶん（oversimplifyを含んでいるはずだし見当違いだったらごめんなさい）楕円型PDEの理論から保証される技術なのだと思っていて、これも似た（そしてずっと高度な形で）大域的な幾何学を扱うために役に立っているんだろうなぁ...と思った。

お昼は学科の友人を誘って、北大の先輩とご一緒した。古田先生の集会だから当然とはいえやわらかめの幾何の人ばかりで私は場違いだった感じがするが、それなら割り切って色々教えてもらおうという魂胆だった。Kirby 計算について少し話を聞かせてもらった。Morse 理論で見るハンドル分解を４次元でやると、普通に考えれば図に描いて扱うのは難しそうだが、それをする技術だ、という話だったと認識している。

午後は主に Atiyah-Singer の指数定理に関連した内容だったと思う。解析的指数を計算するときに、ホロノミーが消えているような格子点に局所化して計算することができるという話だったり、あるいは Dirac 作用素自体を近似する"メゾスコピックな"離散化を構成して指数を有限的な対象で計算できるようにするだとか、Spin 構造というのを考えていろいろ統一的に扱うだとかそういう話だったと思うが午前中の話以上に私の知っている数学から遠い話ばかりで色々難しかった。Clifford 束についてちょうど木曜日に先輩から少し教えてもらっていたのがなかったら初っ端の定義で心が折れていたと思う。指数定理の話も（熱の話と関連して）よく聞くが、関数解析が分からないのでずっと敬遠してきたし、これから学ぶモチベーションも正直無い。それでも研究の話は聞いていると（どうでもいいものも含め）いろいろ発見があって面白い。例えば Riemann-Roch-Hirzeburch という語順を初めて聞いたし、Grassmann 束上の普遍束を「標準束」と言う人もいるのかと思ったり、私たちの知っている標準束が Spin 幾何の文脈で謎の表示をされていて目が飛び出たりした。ケツさえ痛くなかったら最高の時間だった。もうあと１ヵ月は Nissay Lecture Hall の椅子に座りたくない。というかもうコモンルームのソファ以外の椅子には座りたくない。

終わってから昨日話に上がっていた同クラの物理学徒に会った。お互い交換できる情報がたくさんありそうだったので、また今度勉強会でもしようという話になった。自分で物理の理解をひとつひとつ積み上げていくのはさすがに大変すぎるなぁと思っていたし、私の方でも物理の人はさすがにこういう理解の仕方はしていないだろうなぁと思っていた箇所がたくさんあったので、非常に良い話だ。今日は談話会とはやはり別の層の知り合いがたくさん来ていて、休憩時間などでも色々お話しできて楽しかった。直接言うべきことや聞くべきことは、あるものだ。
